Stage 4 — пузырьки сообщений

Скрипт рассчитан на проект после Stage 2 и Stage 3.
Он добавляет направление сообщений из Rust:
- OUT — ваше сообщение, справа, фиолетовое;
- IN — сообщение собеседника, слева, чёрное.

Запускать из корня проекта:
python3 update_ui_stage4.py

После этого:
git add .
git commit -m "Add incoming and outgoing message bubbles"
git push
